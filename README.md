# ⚖️ المحامي الشامل

<div dir="rtl">

### 🤖 الذكاء الاصطناعي المتقدم (Agent)

النظام يحتوي على **وكيل ذكي (AI Agent)** قادر على:
- ✅ **البحث في البيانات** (قضايا، موكلين، مستندات)
- ✅ **تنفيذ أوامر** (إنشاء قضية، إضافة مهمة، تأجيل جلسة)
- ✅ **استخراج التقارير** (مالي، إحصائي، مستحقات متأخرة)

**17 أداة متاحة للـ AI:**
```
search_cases | get_case_details | create_case | update_case
add_session | postpone_session
search_clients | get_client_details | create_client
search_documents
create_task | list_tasks
list_appointments | create_appointment
get_finance_summary | get_overdue_payments | get_stats
```

- بوت تليجرام كامل كمساعد بعيد
- أوامر سريعة: `/start`, `/help`, `/stats`, `/appointments`, `/tasks`
- استعلام بالعربية الطبيعية
- أمثلة:
  - "اعرض قضاياي النشطة"
  - "ما جلسات الغد؟"
  - "فيه مستحقات متأخرة؟"
  - "لخص قضية رقم 2024/001"

### 🔐 نظام الصلاحيات المتقدم

5 أدوار مع صلاحيات مختلفة:

| الدور | الصلاحيات |
|------|----------|
| 🔴 **مدير** | صلاحيات كاملة + إدارة المستخدمين |
| 🟢 **محامي** | جميع الأقسام عدا الأمان والنسخ |
| 🔵 **مساعد قانوني** | قضايا، موكلين، مستندات، مهام |
| 🟡 **عضو** | مهام ومواعيد + عرض البيانات |
| 🟣 **متدرب** | عرض البيانات فقط للتعلم |

## 🚀 التثبيت السريع (5 دقائق)

### ⚠️ مهم جداً قبل البدء:
1. تأكد من تثبيت **Bun** من: https://bun.sh
2. تأكد من وجود ملف `.env` في مجلد المشروع

### الطريقة 1: باستخدام Bun (موصى به)

```bash
# 1. تثبيت الحزم
bun install

# 2. نسخ ملف البيئة (إذا لم يكن موجوداً)
cp .env.example .env

# 3. إعداد قاعدة البيانات (مهم جداً!)
bun run setup

# 4. (اختياري) إضافة بيانات تجريبية
bun run seed

# 5. تشغيل النظام
bun run dev
```

### الطريقة 2: باستخدام npm

```bash
# 1. تثبيت الحزم
npm install

# 2. نسخ ملف البيئة
cp .env.example .env

# 3. إعداد قاعدة البيانات (مهم جداً!)
npx prisma generate
npx prisma db push

# 4. (اختياري) إضافة بيانات تجريبية
npx prisma db seed

# 5. تشغيل النظام
npm run dev
```

### الطريقة 3: أمر واحد (setup + seed + dev)

```bash
bun install && cp .env.example .env && bun run setup && bun run seed && bun run dev
```

### على Windows (PowerShell):

```powershell
# 1. تثبيت الحزم
bun install

# 2. نسخ ملف البيئة
Copy-Item .env.example .env

# 3. إعداد قاعدة البيانات
bun run setup

# 4. تشغيل النظام
bun run dev
```

### 3. أول تسجيل دخول

افتح المتصفح على: `http://localhost:3000`

**بيانات الدخول الافتراضية:**
- **رمز PIN:** `1234`
- **أو البريد:** `admin@lawyer.local`
- **كلمة المرور:** `1234`

## ⚙️ الإعداد بعد التثبيت

### 1. إعداد الذكاء الاصطناعي

1. اذهب إلى **الإعدادات → تبويب "الذكاء AI"**
2. أدخل:
   - **Base URL:** `https://api.freemodel.dev/v1` (أو أي مزود متوافق مع OpenAI)
   - **API Key:** مفتاحك من المزود
   - **Model:** `gpt-5.5` (أو أي نموذج متاح)
3. اضغط **"حفظ الإعدادات"**
4. اضغط **"اختبار الاتصال"**

> 💡 يمكن إدخال هذه القيم في ملف `.env` أو من واجهة الإعدادات (الواجهة تتجاوز ملف .env)

### 2. إعداد تليجرام (اختياري)

#### إنشاء البوت:
1. على تليجرام، ابحث عن `@BotFather`
2. أرسل `/newbot`
3. اختر اسماً ومعرّفاً للبوت
4. انسخ **Bot Token** (مثل: `123456789:ABCdef...`)

#### تفعيل البوت في النظام:
1. اذهب إلى **الإعدادات → تليجرام**
2. الصق **Bot Token** واضغط **"حفظ الرمز"**
3. افتح البوت على تليجرام وأرسل `/start`
4. سيرد البوت بمعرف الشات الخاص بك
5. انسخ معرف الشات وأضفه في **"المعرفات المصرح لها"**
6. اضغط **"فحص"** للتأكد من عمل البوت
7. اضغط **"إرسال رسالة تجريبية"** للتأكد

#### تشغيل خدمة البوت:
```bash
# في نافذة منفصلة
cd mini-services/telegram-bot
bun run dev
```

### 3. إعداد بيانات المكتب

1. **الإعدادات → عام:**
   - اسم المكتب
   - اسم المحامي الرئيسي
   - رقم القيد بالنقابة
   - العملة

### 4. إضافة المستخدمين (للمدير فقط)

1. اذهب إلى **الإعدادات → المستخدمون**
2. اضغط **"مستخدم جديد"**
3. أدخل:
   - الاسم
   - البريد الإلكتروني
   - كلمة المرور
   - رمز PIN
   - **الدور** (مدير/محامي/مساعد/عضو/متدرب)
4. اضغط **"عرض الصلاحيات"** لمراجعة ما يمكن لكل دور الوصول إليه

## 🏗️ البنية التقنية

### التقنيات المستخدمة:
- **Frontend:** Next.js 16 + React 19 + TypeScript 5
- **UI:** Tailwind CSS 4 + shadcn/ui
- **Database:** Prisma ORM + SQLite (محلي)
- **State:** Zustand + TanStack Query
- **AI:** OpenAI-compatible API (Function Calling)
- **Bot:** Bun + Telegram Bot API (Polling)
- **Icons:** Lucide React
- **Charts:** Recharts

```bash
bun run db:push
# ثم أعد تشغيل الخادم

```

### "المفكر القانوني لا يعمل"
1. اذهب إلى **الإعدادات → الذكاء AI**
2. تأكد من إدخال API Key صحيح
3. اضغط **"اختبار الاتصال"**
4. إذا فشل، تحقق من:
   - Base URL صحيح
   - API Key صالح
   - النموذج (Model) متاح

### "البوت لا يستجيب"
1. تأكد من تشغيل خدمة البوت:
   ```bash
   cd mini-services/telegram-bot
   bun run dev
   ```
2. تأكد من إدخال **Bot Token** صحيح في الإعدادات
3. تأكد من إضافة **معرف الشات** في القائمة المصرح لها
4. أرسل `/start` للبوت للحصول على معرفك
5. اضغط **"فحص"** في الإعدادات للتأكد

### "الصفحة بيضاء"
1. انتظر 10-15 ثانية للتحميل الأولي
2. تحقق من Terminal للأخطاء

   ```bash
   bun run dev
   ```
