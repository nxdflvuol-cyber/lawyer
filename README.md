# المحامي الشامل - دليل التشغيل المحلي

## المتطلبات الأساسية
- Node.js 18+ أو Bun
- npm أو bun

## خطوات التشغيل

### 1. تثبيت الحزم
```bash
bun install
# أو
npm install
```

### 2. إعداد ملف البيئة (.env)
أنشئ ملف `.env` في المجلد الرئيسي بالمحتوى التالي:
```
DATABASE_URL=file:./db/custom.db

# إعدادات مزود الذكاء الاصطناعي
AI_PROVIDER_BASE_URL=https://api.freemodel.dev/v1
AI_PROVIDER_API_KEY=fe_oa_547559d4320b3dc6feddcad8b26a234f39b6b9d726798bf8
AI_PROVIDER_MODEL=gpt-5.5
```

### 3. تهيئة قاعدة البيانات (مهم جداً!)
```bash
bun run db:push
# أو
npx prisma db push
```
**هذه الخطوة ضرورية** - بدونها لن يعمل تسجيل الدخول!

### 4. تشغيل الخادم
```bash
bun run dev
# أو
npm run dev
```

### 5. فتح المتصفح
```
http://localhost:3000
```

## حل المشاكل الشائعة

### مشكلة: "حدث خطأ أثناء تسجيل الدخول"
**السبب:** قاعدة البيانات غير مهيأة

**الحل:**
```bash
bun run db:push
```
ثم أعد تشغيل الخادم.

### مشكلة: "تعذر الاتصال بقاعدة البيانات"
**السبب:** ملف `.env` غير موجود أو مسار قاعدة البيانات خاطئ

**الحل:**
1. تأكد من وجود ملف `.env`
2. تأكد من وجود السطر: `DATABASE_URL=file:./db/custom.db`
3. شغّل: `bun run db:push`

### مشكلة: المفكر القانوني لا يعمل
**السبب:** إعدادات مزود الذكاء الاصطناعي غير صحيحة

**الحل:**
1. اذهب إلى: الإعدادات → تبويب "الذكاء AI"
2. أدخل:
   - Base URL: `https://api.freemodel.dev/v1`
   - API Key: مفتاحك
   - Model: `gpt-5.5`
3. اضغط "حفظ الإعدادات"
4. اضغط "اختبار الاتصال"

### مشكلة: الصفحة بيضاء
**السبب:** الخادم لم يبدأ بعد أو خطأ في التجميع

**الحل:**
1. انتظر 10-15 ثانية بعد بدء الخادم
2. تحقق من الطرفية لرؤية الأخطاء
3. أعد تشغيل الخادم: `bun run dev`

## الأوامر المفيدة

| الأمر | الوصف |
